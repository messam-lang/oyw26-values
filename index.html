  4. 4 Add it to your email

    Gmail
    1. Settings (gear) → See all settings → scroll to Signature.
    2. Create new, name it, then click the Insert image icon in the editor.
    3. Upload tab → choose the GIF you downloaded → Select.
    4. Scroll down and Save changes.
    Outlook on the web and new Outlook
    1. Settings (gear) → Accounts → Signatures.
    2. Create or edit a signature, then click the Insert pictures inline icon.
    3. Choose the GIF → Save.
    Outlook for Windows (classic)
    1. File → Options → Mail → Signatures…
    2. New, then use the Insert Picture icon to add the GIF.
    3. Classic Outlook does not animate GIFs. Recipients on other clients still see the animation.
    Apple Mail
    1. Mail → Settings → Signatures → +.
    2. Drag the GIF from Finder into the signature box.
    3. Untick Always match my default message font if the text looks odd.
